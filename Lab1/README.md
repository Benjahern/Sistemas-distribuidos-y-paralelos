# Laboratorio 1 - Programación paralela con OpenMP

## Estructura

- `src/`: código fuente C++ (`main.cpp` y módulos FFT, datos, métricas, benchmark y visualización).
- `include/`: cabeceras de los módulos.
- `tests/`: pruebas automatizadas.
- `laboratorio_1_openmp_fft_2d.md`: enunciado y requisitos completos.
- `AGENTS.md`: contexto e instrucciones para asistentes de código.

La FFT 2D debe ser separable por filas y columnas, con los modos in-place y Stockham y la inversa escalada por `1/(M*N)`. Consulta el enunciado antes de implementar funcionalidades.
